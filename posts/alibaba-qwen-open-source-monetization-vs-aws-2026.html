开源不赚钱，那阿里图什么？拆解通义千问"开源—云—电商 Agent"三级变现逻辑

AI行业观察 2026-06-27 · 13 分钟

一个绕不开的灵魂拷问

通义千问（Qwen）在 Hugging Face 上的累计下载量，2026 年初已突破 7 亿次，阿里官方口径更是"超过 10 亿次、衍生模型超 20 万个、支持 119 种语言"。无论用哪个数字，它都是全球被下载、被二次开发最多的开源大模型家族。

但每次阿里发开源模型，评论区总有同一个问题冒出来："免费开源，那你到底靠什么赚钱？"

这不是抬杠。纯做开源模型的公司，确实普遍困在变现难题里——权重都白送了，用户下载回去自己部署，一分钱不付，模型公司图什么？

阿里给出的答案，藏在集团主席蔡崇信 2026 年 2 月在迪拜世界政府峰会上的一句话里。他把开源 AI 玩家分成两类：一类是纯模型开发商，要直接从开源模型变现，"过程中面临本质上的挑战"；另一类是像阿里、Google 这样的全栈科技企业，从云基础设施、基础模型到应用层全都自己做，可以"在其他技术层捕捉价值"。蔡崇信原话大意是：千问是开源的，我们同时经营云业务；当用户在我们的基础设施上训练、开发、推理，我们就实现了变现。

一句话戳破了天机：对阿里来说，开源模型本身不是商品，而是把开发者引到自家云上的"钩子"。 这篇文章就来拆解这套"开源造势—云上收钱—电商 Agent 闭环"的三级变现逻辑，并和大洋彼岸的 AWS 做个镜像对比，看看 Agent 时代两条截然不同的 AI 变现路，到底谁更稳。

第一级：开源，是最便宜的获客

先说清楚一件事：阿里的开源不是慈善，是精算过的市场费用。

把模型权重以 Apache 2.0 这种宽松许可证免费放出去，换来的是三样东西：

  • 规模与心智：10 亿次下载、20 万个衍生模型，意味着全球开发者在拿 Qwen 当默认底座。我们之前在《2026 开源大模型选型指南》里就提到，Qwen 系列几乎是开源阵营里尺寸最全、生态最广的一支。连我们拆解过的 Ornith-1.0 这种第三方模型，都是直接拿 Qwen 3.5 当预训练底座做后训练——这就是生态绑定的力量。
  • 真实企业客户：Airbnb 用 Qwen 做 AI 客服 chatbot，Pinterest 把 Qwen 和自研模型并用。这些客户一旦在 Qwen 上跑通业务，迁移成本就成了阿里的护城河。
  • 品牌与话语权：在中文和亚太市场，"开源最强"的标签本身就是营销，能反哺阿里云的销售。

关键在于，这笔"市场费用"的回收口，不在模型本身，而在下一级。

第二级：云，才是真正的收银台

开源把人引进门，阿里云负责收钱。这一级的逻辑是经典的"羊毛出在猪身上"——你免费用模型，但训练、微调、推理的算力得在我这买。

数据很能说明问题：

  • 阿里云 2025 年 9 月季度收入同比增长 34%，其中 AI 相关产品收入连续 9 个季度实现三位数同比增长。
  • 据 IDC 2025 下半年报告，中国大模型训推公有云市场规模约 79 亿元，阿里云以 42.2% 份额位列第一，同比增长 116%。
  • 集团给阿里云定的目标是五年内云收入达 1000 亿美元，复合年增长率超过 40%。

为了喂饱这台收银机，阿里在基建上下了血本：从 2025 年 2 月宣布的 3800 亿元人民币，到 2026 年中被报道的三年约 690 亿美元 AI 与云基础设施投入，公司 80% 以上的开放岗位都打上了 AI 标签。

这就解释了为什么阿里愿意一边开源、一边砸钱建数据中心：开源模型跑得越火，云上的算力消耗就越多，越多的推理和微调发生在阿里云，变现就越扎实。 模型是引流的，算力才是计费的。

第三级：旗舰转闭源 + 电商 Agent，把毛利留住

如果说前两级是阿里这两年一直在做的，那 2026 年最值得注意的，是它在变现链条顶端的两个新动作。

动作一：旗舰模型开始转向闭源 API

从 2025 年 9 月的 Qwen3-Max 起，阿里的旗舰模型开始"只给 API、不放权重"。到 2026 年 3 月底，三天内连发三款闭源模型（图像生成升级、多模态的 Qwen3.5-Omni、以及主打 agentic coding + 100 万 token 上下文的 Qwen3.6-Plus），全部面向企业买家，输入价低至 2 元/百万 token（约 0.28 美元）。同期阿里云存储价格上调最高 34%。

这个转向的潜台词很清楚：开源负责走量和造势，闭源旗舰负责守住高毛利。 开发者友好的中小尺寸继续开源维持生态，但最强、最赚钱的能力放进付费 API，避免"白送旗舰"。

动作二：把 Agent 接进电商，做 agentic commerce

这是阿里区别于所有对手的杀手锏。它把 Qwen 重新定义为"企业流程里的执行层"，而不只是聊天助手：

  • 企业侧：百炼（Model Studio）做模型服务平台，2026 年 3 月推出企业级 agentic 平台 Wukong（悟空），旗舰模型直接插入。
  • 消费侧 + 电商闭环：千问 App 月活已破 1 亿，升级为整合购物、实时零售、旅游出行的跨平台智能助手，把 Agent 接进淘宝和支付宝，让 AI 自主完成下单、支付等任务。

这一步的想象空间在于：当 Agent 能自主交易，阿里就能在交易环节而不只是 token 调用上变现——这是它坐拥淘宝、支付宝才能玩的牌。关于 Agent 真正落地企业流程的难点，可以参考我们的《企业 AI Agent 部署指南》。

镜像对比：阿里的"全栈国家队" vs AWS 的"中立瑞士"

把视线移到大洋彼岸，AWS 给出了一条几乎相反的路。理解这组对比，就理解了 Agent 时代两种 AI 变现哲学。

AWS 的选择是：我不下场做最强模型，我做所有模型的货架和收银台。 它的 Bedrock 平台上架了 100 多个第三方模型，从 Anthropic 的 Claude 到 Google、Meta，2026 年 6 月连曾经被微软"独占"的 OpenAI GPT-5.5/5.4 和 Codex 都上了 Bedrock，且定价对齐官方、用量计入 AWS 消费承诺。有评论直接说，AWS 靠"成为中立聚合层"赢下了云 AI 市场之争，其 AI 业务收入 run rate 已超 150 亿美元。

两条路的核心差异，一张表看清：

维度 阿里巴巴 AWS
自研模型 自研 Qwen，开源 + 闭源旗舰双轨 不自研主力前沿模型
平台定位 全栈自有：模型 + 云 + 应用 + 电商 中立聚合层：第三方模型的货架
关键动作 旗舰转闭源 API、Agent 接入淘宝/支付宝 把 OpenAI、Claude 等全拉上 Bedrock
变现核心 云算力 + 闭源 API + 电商 Agent 交易 云算力 + 跨模型 token 流水 + 合规增值
护城河 开源社区 + 中文/亚太 + 自有交易场景 企业信任 + IAM/VPC 合规 + 模型中立
主要风险 自研巨额 capex、技术与团队风险 模型层高毛利让给了模型厂商

打个比方：AWS 像"瑞士"——保持中立，谁都能上架，靠当所有人的收银台和合规管家赚钱；阿里像"全垂直整合的国家队"——从算力到电商一条龙，把价值尽量留在自家全栈里。

两者并非全无共识：都把云算力当作压舱石。但分歧在于模型层——AWS 主动放弃自研、把高毛利让给 Anthropic 和 OpenAI，换来轻资产和中立性；阿里坚持自研，多了"模型话语权"和"电商 Agent 闭环"两张牌，代价是要扛住巨额资本开支和自研失败的风险。

风险：这套飞轮也有几个裂缝

阿里的逻辑自洽，但并非没有隐忧，公众号读者尤其该警惕这几点：

  • 闭源化可能反噬社区。开源辛苦建起的护城河，正被旗舰闭源化"抽干去浇另一块田"。Pinterest 的技术高管就直言，开源近来已大幅缩小与闭源的性能差距。阿里赌的是"闭源能重新拉开差距、企业愿为距离付费"——这个假设未必永远成立。
  • 团队动荡。Qwen 的灵魂人物林俊旸于 2026 年 3 月离职，留下一句"me stepping down. bye my beloved qwen"，接任者来自 Google DeepMind 的 Gemini 团队。社区有声音担忧："用消费 App 的 DAU 逻辑去管基础模型团队，别怪创新曲线变平。"
  • 地缘与合规摩擦。2026 年 6 月，Anthropic 向美国参议院指控，与阿里 Qwen 实验室相关的操作方在 6 周内用约 2.5 万个欺诈账户、发起近 2880 万次未授权的 Claude 调用以蒸取其能力。需要强调：这目前是 Anthropic 的单方指控，尚无第三方定论，但它折射出阿里 AI 出海正面临的地缘与合规阻力在加大。关于中美 AI 的这种结构性摩擦，我们在《Claude 5 停服与中国 AI 的机会》里也聊过。
  • 回报周期与资本开支错配。690 亿美元的投入对应的回报周期很长，短期内利润端会承压，估值已部分提前price in 了 agentic commerce 的乐观预期。

小结

阿里从来没指望靠开源模型本身赚钱，它图的是用开源换规模和开发者心智，再用全栈（云算力 + 闭源旗舰 + 电商 Agent）把规模变成现金流。 这是一套"开源造势、全栈收钱"的三级飞轮。

它和 AWS 的"中立货架"模式形成镜像：AWS 把模型层让出去、专心做平台收过路费；阿里坚持自研、把价值留在自家全栈里。Agent 时代真正的分水岭，可能不在于谁的模型跑分更高，而在于谁能把"Agent 自主执行"接进真实交易场景——这恰恰是阿里靠淘宝、支付宝有机会建立、而 AWS 在结构上不具备的差异化优势。

当然，飞轮能不能持续转下去，取决于阿里能否扛住闭源反噬、团队动荡和地缘摩擦这三道裂缝。未来 12 个月，会给出答案。
