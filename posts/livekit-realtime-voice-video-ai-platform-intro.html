引言：为什么 LiveKit 值得关注？

2025–2026 年，AI 语音助手正从「文本对话」向「实时语音交互」演进。OpenAI 高级语音模式、Google Gemini Live 等产品展示了多模态实时对话的潜力，但开发者要自己搭建一套低延迟、可扩展的实时音视频管道并不容易。

LiveKit 正是为了解决这个问题而生——它是一个开源的实时音视频平台，提供 WebRTC SFU 媒体服务器 + AI Agents 框架，让开发者可以快速构建生产级的语音 AI 智能体、视频会议、直播等应用。

目前 LiveKit 在 GitHub 上拥有 18,800+ ⭐，注册开发者超过 200,000，已被多家 AI 实验室和财富 500 强企业采用。

一、LiveKit 是什么？

LiveKit 是一个端到端的实时音视频 + AI Agent 开源平台，核心由两部分构成：

组件 说明 技术栈
LiveKit Server WebRTC SFU 媒体服务器 Go (Golang)
LiveKit Agents AI 智能体框架 Python / Node.js
LiveKit Cloud 托管云服务 全球边缘网络部署
Client SDKs 多平台客户端 JS/Swift/Kotlin/Flutter/Rust
Egress/Ingress 录制与推流 Go
SIP 电话系统对接 Go

核心理念

LiveKit 的架构围绕 Room（房间） 和 Participant（参与者） 两个核心概念：

  • Room：一个实时通信会话空间，参与者可以在其中发布和订阅音视频轨道
  • Participant：可以是人类用户（通过浏览器/App），也可以是 AI Agent（通过 Agents SDK）
  • Track：音频、视频或数据流，参与者发布和订阅的基本单位

Agent 在 LiveKit 中被视为「一等参与者」——它们像用户一样加入 Room，处理实时音视频流，并将结果发布回 Room。

二、核心架构：WebRTC SFU

LiveKit 的核心是一个高性能的 WebRTC SFU（Selective Forwarding Unit），使用 Go 语言编写，基于 Pion WebRTC 实现。

关键特性

  • 可扩展性：分布式 SFU 架构，支持水平扩展和多区域部署
  • 低延迟：基于 UDP 的 WebRTC，端到端延迟可低至 200ms 以内
  • Simulcast（联播）：发送端同时发布多个分辨率/码率的视频流，接收端按需订阅
  • 选择性订阅：客户端只订阅需要的轨道，节省带宽
  • 端到端加密：可选启用 E2EE，保障通信隐私
  • SVC 编解码：支持 VP9、AV1 等可伸缩视频编码
  • Webhook 与事件：房间事件通过 Webhook 通知后端服务
  • 发言人检测：自动识别当前发言人

三、LiveKit Agents：AI 语音智能体框架

Agent Builder（无代码）

LiveKit 在 2026 年推出了 Agent Builder——一个浏览器内的可视化工具，无需写代码即可构建和部署语音智能体：

  • 拖拽式配置 STT / LLM / TTS 管道
  • 内置语音活动检测 (VAD) 和中断处理
  • 一键部署到 LiveKit Cloud

快速上手代码示例

以下是一个简单的语音智能体（Python）：

from livekit.agents import AgentSession, Agent, AutoSubscribe, JobContext
from livekit.plugins import deepgram, openai, cartesia, silero

async def entrypoint(ctx: JobContext):
    await ctx.connect()

    session = AgentSession(
        stt=deepgram.STT(),
        llm=openai.LLM(model="gpt-4o"),
        tts=cartesia.TTS(),
        vad=silero.VAD(),
    )

    await session.start(
        agent=Agent(),
        room=ctx.room,
        auto_subscribe=AutoSubscribe.AUDIO_ONLY,
    )

Node.js (TypeScript) 版本：

import { AgentSession, Agent, AutoSubscribe } from "@livekit/agents";
import * as deepgram from "@livekit/agents-plugin-deepgram";
import * as openai from "@livekit/agents-plugin-openai";
import * as cartesia from "@livekit/agents-plugin-cartesia";
import { SileroVAD } from "@livekit/agents-plugin-silero";

const session = new AgentSession({
    stt: new deepgram.STT(),
    llm: new openai.LLM({ model: "gpt-4o" }),
    tts: new cartesia.TTS(),
    vad: new SileroVAD(),
});

await session.start({
    agent: new Agent(),
    room: ctx.room,
    autoSubscribe: AutoSubscribe.AUDIO_ONLY,
});

六、工程实践：构建生产级语音 AI Agent 的关键指标

根据 Fora Soft 等工程团队的实战经验，将 LiveKit 语音智能体投入生产需要关注以下核心指标。

延迟预算：人类听感的「红线」

语音 AI 是否「听起来自然」，延迟是首要因素，模型质量其次：

  • 管道模式（STT → LLM → TTS）：完整的端到端延迟必须控制在 800ms 以内，用户才会感觉对话流畅
  • 语音到语音模式（Speech-to-Speech）：端到端延迟可低至 300ms，但需要绑定单一供应商（如 OpenAI Realtime API）
  • LiveKit 的 WebRTC 传输层自身贡献的延迟极低（UDP 直连通常在 50–100ms），主要延迟来自 AI 模型处理

2026 年推荐供应商组合

Fora Soft 推荐的「甜点组合」，可在 550–700ms 内完成一轮对话：

环节 推荐服务 特点
语音识别 (STT) Deepgram Nova-3 毫秒级转录，准确率极高
语言模型 (LLM) Claude Haiku 4.5 速度与智能的最佳平衡
语音合成 (TTS) Cartesia Sonic-3 / Deepgram Aura-2 自然度接近人类，延迟低

成本模型

语音 AI 的生产成本远低于大多数人的直觉：

  • 管道模式全部成本：约 $0.05–$0.15/分钟（包含 STT + LLM + TTS）
  • 相比人工客服中心每分钟 $1–$3 的成本，AI 语音可降低 80–95% 的运营支出
  • LiveKit Cloud 提供免费月度额度，适合开发和测试阶段

何时选择 LiveKit

LiveKit 最适合以下场景： - 月通话量 > 10,000 分钟：此时自建比托管平台（如 Retell、Vapi）更经济 - 需要自定义对话流程：LiveKit 提供完整的 Python/Node.js 控制能力 - 需要可观测性：内置每轮延迟指标、对话转录、通话录音 - 需要电话接入：通过 Telnyx 或 Twilio 实现 PSTN 电话桥接

小而简单场景的替代方案：如果月通话量低于 10,000 分钟且流程简单，Retell 或 Vapi 等托管平台可以更快上线（小时级 vs LiveKit 的 1–3 周）。

噪声消除与合规

  • Krisp 噪声消除：LiveKit 内置授权，但从 2026 年 5 月 1 日起按量计费（约 $0.002–$0.004/分钟），干净音频环境可关闭
  • 合规要求：平台不代管合规责任。外呼场景需自行确保 TCPA（美国电话消费者保护法）、HIPAA（医疗隐私）、GDPR（欧洲数据保护） 以及两方录音同意等法律要求

整体工程投入

构建一个生产就绪的语音 Agent，LiveKit 路径需要 1–3 周的工程时间（含 STT/LLM/TTS 集成、对话流程编排、电话接入、测试调优）。相比之下，Retell 等托管平台宣称 3 小时可上线，但定制化空间有限。

八、快速上手

本地开发

# 1. 安装 LiveKit Server（MacOS）
brew install livekit

# 2. 启动开发服务器
livekit-server --dev

# 3. 安装 LiveKit CLI
# MacOS: brew install livekit-cli
# Linux: curl -sSL https://get.livekit.io | bash

# 4. 生成测试 Token
lk token create \
    --api-key devkey --api-secret secret \
    --join --room my-room --identity user1 \
    --valid-for 24h

# 5. 打开演示页面测试
# 访问 https://example.livekit.io 输入 Token 连接
