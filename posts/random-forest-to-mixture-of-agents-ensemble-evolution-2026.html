从随机森林到 Mixture-of-Agents：多模型集成从传统机器学习到大模型时代

AI技术趋势 2026-07-19 · 18 分钟

当 $0.12 打败了 $1.71

先看一组数字。在 DRACO 公开评测的 Brave Search 组里，单个顶尖模型 GPT-5.6-sol 拿到 63.99 分，每完成一个任务要花 $1.71。而一个只由 DeepSeek、GLM、Kimi、Qwen 四个国产开源模型组成的集成方案 OpenSquilla，拿到了 64.09 分——分数略高，成本却只有 $0.12/任务，便宜了十几倍。

换句话说，一群"没那么贵"的模型组队协作，在质量和成本两条线上同时压过了单个最强模型。这不是孤例。业界的模型路由实践显示，把大部分请求分流到便宜模型、只在必要时升级到贵模型，能在质量几乎不掉的前提下 削减 50%–85% 的 API 成本（LLM Routing in Production）。

"三个臭皮匠，顶个诸葛亮"这句老话，突然在大模型时代成了一条正在崛起的技术路线。

但这里有个值得深挖的问题：用多个模型联合起来提升效果，这件事传统机器学习早就在做了——随机森林、XGBoost 这些统治了 Kaggle 十几年的算法，本质都是集成模型。那么，大模型时代的"多模型集成"，和传统机器学习的"集成学习"，到底是同一回事，还是彻底换了个战场？

这篇文章就从随机森林讲到 Mixture-of-Agents，把这条演进脉络和两代集成的本质区别一次讲清楚。

说明：本文数据来自公开评测、arXiv 论文与厂商公开资料，引用内容均经改写以符合授权合规要求，关键数字建议以官方来源为准。

一、传统机器学习：为什么"人多力量大"

集成学习（Ensemble Learning）是传统机器学习里一个极其成熟的核心方向。它的全部存在意义，就是"用多个模型联合预测，去超过任何单个模型"。

为什么组合起来会更准

核心直觉很简单：不同的模型会犯不同的错误。如果把它们的预测组合起来（投票、平均、加权），每个模型的随机误差会相互抵消，剩下的预测就比任何单个模型都更稳、更准（Ensemble Learning Methods）。

用理论语言说，这背后是 偏差-方差-多样性分解（bias–variance–diversity decomposition）。单个模型的失败往往来自两个方向：偏差太高（欠拟合，学不到规律）或方差太高（过拟合，对训练数据里的噪声过度敏感）。集成能同时改善这两类误差来源。

这里有一个常被忽视、却至关重要的前提：基模型之间必须有差异性（diversity）。如果几个模型几乎一模一样、犯的错也一样，那把它们平均起来毫无收益——误差没有被抵消，只是被复制了一遍。所以业界有句经验之谈：一个稍弱但和别人不相关的模型，往往比一个更强但和大家雷同的模型更有价值（Ensemble Diversity & Bias-Variance）。

三大流派

传统集成学习主要有三条路线，各自针对不同的误差来源。

Bagging（装袋） —— 主打降方差。

它并行训练多个模型，每个模型在原始数据的一个随机采样子集（bootstrap 采样）上独立训练，最后用投票或平均把结果合起来。因为每个模型看到的数据略有不同，它们会自然产生差异性。

  • 代表算法：随机森林（Random Forest），用几百棵决策树投票。它进一步在每次分裂时随机挑选特征子集，人为制造更多多样性，效果非常稳健。

Boosting（提升） —— 主打降偏差。

它串行训练，每个新模型都专门去纠正前面模型犯错的那些样本，一步步逼近正确答案。它把一群"弱学习器"逐步锻造成一个强学习器。

  • 代表算法：XGBoost、LightGBM、AdaBoost。这几乎是表格数据竞赛（Kaggle）常年的冠军算法，也是工业界风控、CTR 预估、推荐排序系统的主力。

Stacking（堆叠） —— 主打拉高天花板。

它先训练多个不同类型的基模型，再额外训练一个"元学习器（meta-learner）"，让这个元模型去学习"如何最优地组合基模型的输出"。它的预测上限最高，但工程复杂度也最高。有时一个简单的加权平均或投票，就能接近 Stacking 的效果，成本却低得多（Bagging, Boosting, and Stacking）。

传统集成的四个关键特征

把这些方法抽象一下，传统集成学习有几个鲜明的共性：

  • 集成发生在训练阶段：你在训练时就把一堆模型"组装"成一个整体，产出的是一个可部署的复合模型。
  • 基模型是白盒、可控的：通常同构（都是决策树，或都是某类回归器）、轻量、能拿到概率输出、能重训、能显式调权重。
  • 多样性是你亲手制造的：通过数据采样、特征扰动、损失加权，你能主动控制模型之间有多不一样。
  • 融合方式是数学上定义好的：投票、加权平均、元模型回归，输出是结构化的数值或类别，"谁对谁错"能被机器直接判定。

这套体系的收益来源可以概括成一句话：把一堆弱模型拼成一个强模型，靠误差抵消赚取精度。

二、大模型时代：集成换了个战场

到了大模型时代，"多模型联合"这件事重新火了起来，学界已经有了系统的综述（如《Harnessing Multiple Large Language Models: A Survey on LLM Ensemble》，arXiv:2502.18036）。但当你走近看，会发现玩法和传统集成已经大不相同。

原因在于游戏的初始条件变了。今天市面上有大量开箱即用、各有所长的大模型（GPT、Claude、DeepSeek、Qwen、Kimi、GLM……），它们大多是 异构的、重量级的、黑盒的——你拿不到它们的权重和 logits，不能重训，只能"文本进、文本出"。在这个前提下，"集成"自然演化出了几条新路线。

路线一：Ensemble（输出层集成）

让多个 LLM 各自回答同一个问题，再把它们的回答喂给一个"聚合器"融合成更好的答案。最具代表性的方法是 Mixture-of-Agents（MoA）：多个 proposer 模型先给出候选回答，一个 summarizer 模型再把这些回答综合成最终输出（Is Mixing Different LLMs Beneficial?）。

这在形式上最像传统的 Stacking——都有"基模型 + 一个负责综合的上层"。但区别在于，这里的"元学习器"不是一个训练出来的回归器，而是 另一个大模型在推理时用自然语言做综合。

路线二：Merging（参数层融合）

在权重空间里把多个模型合并，比如对参数做加权平均。这条路要求模型同源（通常是同一个基座微调出来的不同版本），依赖 linear mode connectivity 之类的假设——即同源微调模型在权重空间里位于一个连通的区域，可以平滑地插值合并（Model Merging Survey）。它常用来把一个"安全对齐"的模型和一个"领域专精"的模型合成一个。

路线三：Routing（路由）

不追求"让所有模型都上"，而是根据每个输入的特点，把它分发给"最合适"而非"最强"的那个模型。一个简单的分类问题交给便宜的小模型，一个复杂的推理问题才路由给昂贵的大模型。核心是训练一个路由器去判断"这个 query 该派给谁"。

路线四：Cascade（级联）—— 成本的核心

这是让"$0.12 打败 $1.71"成为可能的关键机制。级联的思路是：先用最便宜的小模型回答，用一个质量估计（QE）模块判断答案是否合格；不合格再逐级升级到更贵、更强的模型。这样一来，只有真正困难或低置信度的查询才会触达昂贵的模型，大量简单查询在第一级就被便宜地解决了（Cluster, Route, Escalate）。

FrugalGPT、RouteLLM 等方案都属于这一大类。它们把优化目标从传统的"纯精度"，彻底转向了 精度 × 成本 × 延迟 的多目标权衡（FrugalGPT / Efficient LLM Inference）。这也解释了 OpenSquilla 那种方案为什么能赢——它优化的根本不是"绝对分数最高"，而是"性价比曲线最优"。

大模型集成的收益来源

如果说传统集成是"把弱模型拼成强模型"，那大模型集成更像是：把一堆各有所长的强模型，编排成一个更划算、更鲁棒的系统。 收益来自 能力互补 + 成本调度，而不只是误差抵消。

关于把多个 LLM 编排成协作系统的更完整讨论，可以参考多智能体协作框架指南；而承载这类路由/级联的基础设施，则可以看LiteLLM AI 网关深度解析。

三、两代集成的本质区别

把两者并排放在一起，差异就非常清楚了。

维度 传统 ML 集成学习 大模型多模型集成
集成发生时机 训练时（组装成一个模型） 推理时（协同已有黑盒模型）
理论根基 偏差-方差-多样性分解，数学闭式 尚在成型，借鉴 MoE / 混合模型视角
基模型 同构、轻量、白盒、可重训 异构、重量级、黑盒、不可训
多样性来源 数据采样 / 特征扰动 / 损失加权（可控） 不同厂商 / 架构 / 训练数据（天然存在，不可控）
融合方式 投票 / 加权平均 / 元模型回归 另一个 LLM 聚合、路由、级联、参数合并
优化目标 精度、泛化 精度 × 成本 × 延迟 多目标
输出形态 数值 / 类别（易判对错） 开放文本（对错难判，靠 QE / 一致性）
典型代表 随机森林、XGBoost、Stacking MoA、FrugalGPT、RouteLLM、OpenSquilla

有三个差异点值得再强调。

第一，集成的时机完全不同。 传统集成是"训练时组装"，你亲手把 N 个模型拼成一个复合模型再拿去部署；大模型集成是"推理时编排"，你面对的是一堆已经训练好、无法改动的黑盒，只能在调用它们的过程中做文章。

第二，你对多样性的掌控力完全不同。 传统集成里，多样性是你主动制造的资源——想要更多样，就换采样方式、扰动特征。大模型集成里，多样性是"天然给定"的（不同厂商用不同数据训出了不同脾气的模型），你无法制造，只能识别和利用。

第三，"对错"的可判定性完全不同。 分类/回归任务的输出是数值，投票平均是数学上闭式的操作，谁对谁错一目了然。而 LLM 的输出是开放式自然语言，很难像分类那样机器判定对错，所以大模型集成不得不引入质量估计、语义一致性、投票+仲裁等间接手段来"猜"哪个答案更好——这是它工程上最棘手的部分。

四、一个容易混淆的中间形态：MoE

聊到这里，很多人会想到 MoE（Mixture-of-Experts，混合专家）。它确实和集成学习思想相通——都是"多个专家分工协作"，中文社区也常把 MoE 类比成集成学习（手撕 sMoE）。但要分清一个关键层级：

  • MoE 是单模型内部的稀疏路由：专家是模型内部的一堆子网络，路由器在训练时就学会了"每个 token 该激活哪几个专家"。它是一个模型内部的机制，对外仍然是一个模型。
  • 本文说的多模型集成是模型之间的外部编排：参与者是多个独立的、完整的模型，编排发生在它们外部。

有意思的是，学界最近开始用 MoE 的视角来理解多模型/多智能体系统——把多智能体的协商过程看成一种输入相关的"混合专家"，从而解释为什么当路由能反映各智能体的真实能力时，多智能体系统能超过单个智能体和静态集成（Multi-Agent Systems are Mixtures of Experts）。所以 MoE 更像是连接两代集成思想的一座桥：它把"集成"的智慧内化进了单个模型的架构里。关于 MoE 本身的工程实践，可参考MoE 后训练加速。

五、成本视角：为什么便宜模型组队能赢

回到开头那个 $0.12 vs $1.71 的问题。为什么一堆便宜模型组队，能在成本和质量上双双压过单个最强模型？拆开来看有三层原因。

第一，大部分任务其实不需要最强模型。 真实工作负载里，简单查询占了绝大多数。用最强模型去回答"今天星期几"这类问题，是巨大的算力浪费。前沿模型的单 token 成本大约是调优良好的开源小模型的 10–50 倍（Model Routing Strategies）。把简单任务分流给便宜模型，成本立刻断崖式下降。

第二，能力互补带来质量增益。 不同模型的强项不一样——有的擅长中文，有的擅长代码，有的擅长数学推理。让它们各自处理擅长的任务，或者对同一个难题各出一份答案再综合，整体质量可能超过任何单个模型在所有维度上的表现。这正是 OpenSquilla 分数能微超 GPT-5.6-sol 的底层逻辑。

第三，鲁棒性更强。 单模型有它系统性的盲区和幻觉倾向。多个来源不同的模型交叉验证，能显著降低"一个模型自信地胡说八道"被直接采信的概率。

当然，这条路不是免费的午餐。它引入了新的工程复杂度：路由器/质量估计器本身要开发和维护、多模型调用带来额外延迟、聚合逻辑可能引入新的错误、多个 API 供应商带来运维和合规负担。是否值得，取决于你的流量规模和对成本的敏感度——流量越大，路由/级联省下的钱越可观。选择底层模型时，可以参考开源大模型选型对比与大模型推理框架对比。

六、如何选型：什么时候用哪种

最后给一份实用的决策参考。

如果你面对的是结构化 / 表格数据（风控评分、销量预测、CTR 预估、用户流失预测等）：

  • 首选传统集成学习。XGBoost / LightGBM 是几乎无脑正确的起点，随机森林是稳健的基线。
  • 需要极限精度、且有工程余力时，再上 Stacking。
  • 这个场景下大模型通常不是最优解，传统集成又快又准又可解释。

如果你面对的是开放式文本任务（问答、写作、代码、Agent 工作流）：

  • 单一任务、预算充足、追求极致质量 → 直接用单个最强模型，别过早优化。
  • 大流量、成本敏感、任务难度分布不均 → 上 Routing + Cascade，让便宜模型扛简单请求，贵模型只处理硬骨头。
  • 追求答案质量上限、能容忍更高成本和延迟 → 用 MoA 这类输出层集成，多模型出稿 + 一个模型综合。
  • 想融合两个同源微调模型的能力 → 考虑 Merging（参数合并）。

一句话原则：传统数据问题优先集成学习；大模型问题先问自己"我优化的是质量、成本还是延迟"，再据此在单模型、路由、级联、MoA 之间做选择。

小结

从随机森林到 Mixture-of-Agents，"多模型联合"这个朴素的想法贯穿了机器学习的两个时代，但它的形态发生了根本变化：

  • 传统集成学习是训练时把一堆弱模型组装成一个强模型，靠误差抵消赚取精度，融合方式是数学上闭式的投票与平均，理论基础扎实。
  • 大模型集成是推理时把一堆现成的黑盒强模型编排成一个更划算的系统，靠能力互补和成本调度取胜，融合靠另一个模型或路由/级联规则，优化的是精度、成本、延迟的多目标平衡。

"三个臭皮匠顶个诸葛亮"的智慧没有变，变的是臭皮匠从"你亲手训练的弱模型"变成了"市面上各有所长的强模型"，而你的角色也从"训练师"变成了"编排者"。当 $0.12 能打败 $1.71 时，会编排，正在成为比会训练更值钱的能力。
